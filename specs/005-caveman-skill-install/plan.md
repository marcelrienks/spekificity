# Implementation Plan: Caveman Skill Install

**Branch**: `005-caveman-skill-install` | **Date**: 2026-06-11 | **Spec**: [spec.md](spec.md)

## Summary

Install the caveman compression skill as a first-class step in `spek init`. For all integrations: fetch `SKILL.md` from the caveman GitHub package and copy it to the integration's skills directory. For the `claude` integration: additionally write `SessionStart` and `UserPromptSubmit` hooks to the project's `.claude/settings.json` so caveman mode activates automatically every session.

## Implementation Breakdown

### Module: `spekificity/caveman/install.py`

#### `install_caveman(project_path, integration) → CavemanInstallResult`

Top-level entry point called from `cli.py`. Orchestrates:
1. `_fetch_skill_content()` — resolve and read SKILL.md
2. `_copy_skill(project_path, integration, content)` — write to skills dir
3. `_install_hooks(project_path)` — Claude-only; ensure global hooks exist + write project settings.json

#### `_fetch_skill_content() → bytes | None`

Resolution order (stops at first success):
1. Read `Path.home() / ".claude/skills/caveman/SKILL.md"`
2. Scan `Path.home() / ".claude/plugins/cache/caveman/caveman/"` for latest SHA subdirectory → read `plugins/caveman/skills/caveman/SKILL.md`
3. `urllib.request.urlopen("https://raw.githubusercontent.com/JuliusBrussee/caveman/main/plugins/caveman/skills/caveman/SKILL.md", timeout=10)`
4. Returns `None` if all fail; logs `[WARN]`

#### `_copy_skill(project_path, integration, content) → str`

Mirrors `copy.py` placement logic:
- Flat integrations (`claude`, `copilot`, `generic`): write to `<skills-dir>/caveman.md`
- Subfolder integrations: write to `<skills-dir>/caveman/SKILL.md`
- If destination exists: return `"skipped"`
- Returns `"installed"` or `"failed"`

#### `_ensure_global_hooks() → bool`

Check `Path.home() / ".claude/hooks/caveman-activate.js"` exists.
If not:
1. Try plugin cache: run `node <cache-path>/bin/install.js --skip-skills --non-interactive`
2. Fallback: run `npx -y "github:JuliusBrussee/caveman" --skip-skills --non-interactive`
Returns `True` if hooks present, `False` on failure.

#### `_write_project_hooks(project_path) → str`

1. Find node: `shutil.which("node")` — return `"failed"` if None
2. Ensure `_ensure_global_hooks()` — return `"failed"` if False
3. Read/parse `project_path / ".claude/settings.json"` — handle JSONC via `_strip_jsonc()`
4. Idempotency check: if `caveman-activate` in any SessionStart command → return `"skipped"`
5. Add hook entries for `SessionStart` and `UserPromptSubmit`
6. Atomic write: temp file + `os.replace()`
7. Returns `"installed"`, `"skipped"`, or `"failed"`

#### `_strip_jsonc(src: str) → str`

Minimal JSONC stripper: removes `//` line comments and `/* */` block comments outside strings, plus trailing commas. Needed because Claude Code's `settings.json` may contain comments.
